<a name="português"></a>
## 🇧🇷 Português

Uma aplicação web de **Soundboard interativo** que reúne efeitos sonoros variados organizados por categorias. O usuário pode navegar entre diferentes páginas temáticas e reproduzir áudios com apenas um clique.

🔗 **Acesse o projeto online:** [brunossilva12-creator.github.io/HarmoniaSonora](https://brunossilva12-creator.github.io/HarmoniaSonora/)

### ✨ Funcionalidades e Categorias
- **Menu de Navegação por Categorias:** Organização dividida em três páginas dedicadas:
  - **🎵 Sons Diversos:** Efeitos sonoros gerais para diferentes situações.
  - **🎮 Sons de Jogos e Relacionados:** Áudios clássicos e efeitos marcantes do universo gamer.
  - **😂 Sons de Memes:** Coleção de áudios populares e virais da internet.
- **Reprodução Instantânea:** Disparo rápido de áudio diretamente pelo navegador ao clicar nos botões.
- **Interface Simples e Responsiva:** Visual direto ao ponto, adaptado para uso tanto no computador quanto no celular.

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do menu e integração de elementos de áudio (`<audio>`).
- **CSS3:** Estilização dos botões interativos, layout e responsividade entre as páginas.
- **JavaScript:** Controle de reprodução dos arquivos de áudio e interação com os botões do soundboard.

### 🚀 Como executar localmente
1. Clone este repositório:
   ```bash
   git clone https://github.com/brunossilva12-creator/HarmoniaSonora
   ```
2. Abra a pasta do projeto e execute o arquivo `index.html` diretamente no seu navegador.

<a name="english"></a>
## 🇺🇸 English

An interactive **web Soundboard** featuring a collection of sound effects organized by category. Users can navigate across themed pages and trigger audio clips with a single click.

🔗 **Live Demo:** [brunossilva12-creator.github.io/HarmoniaSonora](https://brunossilva12-creator.github.io/HarmoniaSonora/)

### ✨ Features & Categories
- **Categorized Navigation Menu:** Organized into three dedicated pages:
  - **🎵 Miscellaneous Sounds:** General sound effects for various situations.
  - **🎮 Gaming & Related Sounds:** Classic audio clips and iconic effects from video games.
  - **😂 Meme Sounds:** A collection of popular and viral internet sound effects.
- **Instant Playback:** Fast audio triggering directly in the browser with a single button click.
- **Clean & Responsive UI:** Straightforward layout adapted for both desktop and mobile devices.

### 🛠️ Technologies Used
- **HTML5:** Semantic structure of the menu and native audio integration (`<audio>`).
- **CSS3:** Interactive button styling, layout design, and multi-page responsiveness.
- **JavaScript:** Audio playback controls and user interaction handling.

### 🚀 How to run locally
1. Clone this repository:
   ```bash
   git clone https://github.com/brunossilva12-creator/HarmoniaSonora
   ```
2. Open the project folder and launch the `index.html` file in your browser.
